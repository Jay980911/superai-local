> **给实现这份文档的 AI/工程师：**
> 这是一份完整的产品实现规格。你的任务是**按本规格还原一个可运行的项目**，界面、交互、文案以本文件 + 视觉真值文件为准，**不要自由发挥设计**。
>
> - **视觉真值**：`bench-ui-ux-prototype.html`（单文件原型，浏览器打开，含 5 个界面状态与全部交互；它同时是像素级参考，遇到规格与原型不一致时**以原型为准**）
> - **设计 token**：`bench-design-tokens.css` / `bench-design-tokens.json`（颜色/字体/间距/圆角的唯一来源，禁止自创数值）

## 0. 执行约定（先读这段）

1. **设计已完成，你负责实现。** 颜色、字号、圆角、间距、图标样式一律取自 token，不允许"顺手改一改"。
2. **实现顺序**：先跑通布局骨架（三栏 + 标题栏）→ 组件与内容 → 交互 → 状态（空态/加载/错误）→ 自查验收清单（§11）。
3. **交付形态**：一个 `npm install && npm run dev` 即可打开的前端项目（默认技术栈见 §9，如用户指定其他栈以用户为准）。
4. **数据**：本期全部用 mock（§8 给了完整文案与数据结构），但组件要按 §10 的接口契约设计，方便后续接真 Agent。
5. **禁止**：引入 UI 组件库（AntD/MUI 等）、引入现成图标库（图标按 §6.6 自绘 SVG）、渐变/玻璃拟态/发光效果、对话区描边卡片。
6. 每完成一屏，对照 §11 验收清单自查一次。

## 1. 产品定义

- **一句话**：桌面端 AI 工作台。选一个工作目录，用对话驱动 AI 执行任务、生成文件/项目，右侧实时查看成果（目录树 / 源码 / 预览）。
- **目标用户**：非开发者为主的通用用户（做汇报、整理文件、生成网页/文档、分析数据），开发者是子集。
- **产品性格**：安静、克制、可信。像一张整理好的工作台，不是一块仪表盘。
- **本期目标（MVP）**：完整实现 UI 层与交互（mock 数据驱动），为 Agent 能力预留接口。
- **非目标**：本期不做后端、不做模型接入、不做移动端、不做多语言。

## 2. 功能范围（三档）

| 档 | 内容 | 本期 |
|---|---|---|
| ① 前端 UI | 5 个界面状态 + 交互 + mock 数据 | ✅ 做这个 |
| ② 桌面壳 | Tauri/Electron：选目录、读文件树、写文件、跑命令 | 接口预留，不实现 |
| ③ Agent | 对话/任务执行/技能/生成项目（接模型） | 接口预留，不实现 |

**用户故事（本期要能"演"出来）**
1. 选择工作目录后，用户用自然语言下达任务（"把 Q3 数据做成汇报页 + 说明文档"）。
2. AI 拆解为步骤执行，过程可见（步骤卡：完成态勾选、耗时）。
3. 产出物出现在右侧成果面板：目录树（新增文件带「新」标）、源码（改动行标记 + 修改者注记）、预览（实时渲染，点元素定位源码）。
4. 用户追加修改（"华东区标红 + 环比"），AI 修改后预览实时刷新，改动可撤销。
5. 任何时候新建对话，进入空态引导；历史会话在左栏可检索、可切换。

### 6.1 主按钮 vs 文字链（重要）
- **实心主按钮**：一屏最多 1 个（如 `打开预览`/`下载全部`/`新建对话`）。墨色底、纸色字、圆角 8。
- **其余动作全部是文字链**：无边框无底色，悬停出现下划线（下划线偏移 3px）。
- **禁止**：多层描边按钮、按钮组边框。

### 6.2 对话区零描边（重要）
- 用户消息 = 软底圆角块（radius 10），**无描边无阴影**。
- AI 消息 = 无容器纯文本。
- 步骤卡/文件卡 = **无容器**（无边框无底色），行与行之间不用分隔线，用间距。
- 只允许保留的线：结构性分栏线（标题栏下沿、面板分界）与表格类内容的行分隔。

### 6.3 输入区
- 软底圆角 12，聚焦时行动色 28% 透明外晕一圈（focus ring）。
- 工具条：`＋ 附件` `✨ 技能`（软底胶囊）`模型 · 均衡 ▾`（文字钮）`自动执行`（带滑块开关，默认开）→ 右侧发送按钮（实心、圆角 11、↑）。
- 下方一行 Mono 小字：`ENTER 发送 · SHIFT+ENTER 换行 …… 读写范围 ~/Documents/Q3汇报`。

### 6.4 成果面板
- 分段控件：软底容器 + 选中项白底浮起（圆角 8，阴影极浅）。
- 目录树行：线性文件图标 + 名称（Mono）+ 说明 + 大小 + `新` 标（行动色浅底小胶囊）。
- 源码：改动行整行浅行动色底 + 左侧竖条；修改者注记 = 白底小胶囊挂在行尾。
- 预览：页面卡片浮在浅暖底上（阴影 0 18px 44px -16px）；点选态 = 行动色虚线框 + 顶部小胶囊标注（含向下小三角）。

### 6.5 状态色使用
- 只在表达状态时用彩色：成功=绿、提醒=琥珀、危险=红、信息=蓝图（工作目录 chip）。
- 其它一律灰阶 + 墨色。

### 6.6 图标系统（自绘 SVG，禁止图标库）
- **24 网格 · 描边 2 · 端点平头（butt）· 拐角尖角（miter）· 单色灰阶**
- **容器类图形（圆/文档/文件夹）= 白色填充 + 墨色描边**；纯线符号（折线、星形）无填充
- 必备图标集：完成（黑圈+白底+黑勾）、进行中（同圈 + 指针）、文件、文件夹、表格、技能星形、数据折线、提示（圈+!）、附件、搜索、设置、折叠/展开、发送
- 图标在界面中的渲染尺寸 18–20px，颜色默认 `--ink-2`，激活/完成态 `--ink`
